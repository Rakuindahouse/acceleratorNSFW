# ebb flow mixer

[ebb and flow](https://htg0707kym-lgtm.github.io/ebb-and-flow-artwork/) をベースにした映像ミキサー。
画面を斜めに分割したパネルに素材を流し、流速・うねり・残像を操作しながら全体の色を変えられます。

## 起動

- **Windows**: `start.bat` をダブルクリック → ブラウザで `http://localhost:8787/` が開きます
  （Python か Node.js が必要。Chrome / Edge 推奨）
- **mac / Linux**: `start.command`

`index.html` を直接開くとサイト素材が読み込めないので、必ずスクリプトから起動してください。

## できること

| 機能 | 操作 |
| --- | --- |
| 好きな画像・動画 | 「画像・動画を追加」/ ドラッグ＆ドロップ / Ctrl+V 貼り付け |
| Spout ソース | 「Spout / カメラ」→ SpoutCam を選んで「追加」 |
| サイトの画像 | 絵の具(19) / 海：青(65) / 海：白(52) をチェックで ON/OFF |
| 素材の混ぜ具合 | 「自分の素材」スライダー（1 で自分の素材だけ） |
| 動き | 分割数・傾き・切替秒・フェード・流速・うねり・残像・ズーム |
| 全体の色 | プリセット、色相・彩度・明るさ・コントラスト・ガンマ、色置換（影/中間/光の3色）、色かぶり、反転、周辺減光 |
| 保存 | 「画像保存」で PNG。設定は自動で記憶 |

キー: `H` パネル表示切替 / `F` 全画面 / `N` 次の配置 / `Space` 押している間だけ高速に明滅。
スライダーはダブルクリックで初期値に戻ります。

## Spout の受け方

ブラウザは Spout を直接受け取れないため、Spout 公式の **SpoutCam** を使います。

1. [Spout](https://spout.zeal.co/) をインストールし、付属の `SpoutCamSettings` で SpoutCam を登録
2. 送りたいアプリ（TouchDesigner / Resolume / OBS + Spout プラグインなど）で Spout 送信
3. このアプリで「Spout / カメラ」→ `SpoutCam` を選択 → 追加

複数の Spout ソースを使う場合は SpoutCam を複数登録してください（SpoutCam1〜4）。
OBS の「仮想カメラ」も同じ手順で使えます。

## 出力を他のアプリに渡す

OBS で このブラウザウィンドウをキャプチャ → OBS の Spout2 プラグイン / 仮想カメラ で送れます。
`H` でパネルを隠し、`F` で全画面にしてから使ってください。

## 素材について

`builtin/` の画像は ebb and flow の公開サイトから取り込んだものです（ライセンス表記なし）。
公開・配布する場合は元の制作者に確認してください。
