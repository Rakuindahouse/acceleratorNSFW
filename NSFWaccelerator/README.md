# ebb flow mixer

[ebb and flow](https://htg0707kym-lgtm.github.io/ebb-and-flow-artwork/) をベースにした映像ミキサー。
画面を斜めに分割したパネルに素材を流し、流速・うねり・残像を操作しながら全体の色を変えられます。

## 起動

`index.html` をダブルクリックするだけで動きます（Chrome / Edge 推奨）。インストールは不要です。
既定のブラウザが Chrome / Edge 以外の場合は、`index.html` を Chrome の画面にドラッグしてください。

## できること

| 機能 | 操作 |
| --- | --- |
| 好きな画像・動画 | 「画像・動画を追加」/ ドラッグ＆ドロップ / Ctrl+V 貼り付け |
| Spout ソース | 受信アプリを起動して「Spout」→ 送信名を選んで「追加」 |
| サイトの画像 | 絵の具(19) / 海：青(65) / 海：白(52) をチェックで ON/OFF |
| 素材の混ぜ具合 | 「自分の素材」スライダー（1 で自分の素材だけ） |
| 動き | 分割数・傾き・切替秒・フェード・流速・うねり・残像・ズーム |
| 全体の色 | プリセット、色相・彩度・明るさ・コントラスト・ガンマ、色置換（影/中間/光の3色）、色かぶり、反転、周辺減光 |
| 音の入力 | 「マイク / ライン」「PCの音」「音声ファイル」 |
| 保存 | 「画像保存」で PNG。設定は自動で記憶 |

キー: `H` パネル表示切替 / `F` 全画面 / `N` 次の配置 / `Space` 押している間だけ高速に明滅。
スライダーはダブルクリックで初期値に戻ります。

## 音に反応させる

元作品と同じく、音で映像が動くようになっています。入力は3種類です。

- **マイク / ライン**: オーディオIF・マイク・VB-CABLE・ステレオミキサーなど。デバイスを選んで「使う」
- **PCの音**: 画面共有ダイアログで画面を選び、「システム音声を共有」をオン（Windows の Chrome / Edge）
- **音声ファイル**: 選んだ曲を再生しながら反応させます（スピーカーからも鳴ります）

音は 低音・中音・高音 に分けて解析し、次のように反映します（スライダー 0 でオフ）。

| スライダー | 反応 |
| --- | --- |
| 入力感度 | 全体の反応の強さ |
| ビート切替 | 低音のアタックで配置を切り替え（右ほど敏感） |
| 最短間隔(秒) | ビート切替が連続しすぎないための間隔 |
| 低音→うねり | 低音でうねりが強くなる |
| 音量→流速 | 大きい音ほど速く流れる |
| 高音→明るさ | 高音で明るくなる |
| ビート→光 | ビートの瞬間に光る |
| 静けさ→残像 | 静かな部分ほど残像が長く残る |

## Spout を受ける

付属の受信アプリ `NSFWaccelerator-Spout.exe` を使います（SpoutCam は不要）。

1. `start.bat` で起動すると、受信アプリ（黒いウィンドウ）も一緒に起動します。この黒いウィンドウは閉じないでください
2. 送る側のアプリ（Resolume / TouchDesigner など）で Spout 出力をオンにする
3. このアプリの「Spout」→ 一覧から送信名を選んで「追加」。何本でも追加できます
4. 上下が逆なら、ソース一覧の「⇅」で反転
5. 重いときは「受信画質」を「軽い」に

初回起動時に Windows が「PCが保護されました」と出したら、「詳細情報」→「実行」を押してください（署名がないため出ます）。
受信アプリの黒いウィンドウには、5秒ごとに受信・送信の fps が表示されます。

## Spout で出力する

「出力」の「Spout出力」を押すと、受信アプリ経由で **NSFWaccelerator** という名前で Spout を送ります。
Resolume などで Spout ソースとして選んでください。上下が逆なら「上下反転」を押します。
出力の解像度は「出力」の解像度設定に従います（1920 × 1080 など）。

NDI で出したい場合は、出力ウィンドウを OBS でキャプチャして [DistroAV](https://github.com/DistroAV/DistroAV) で送ってください。

出力ウィンドウを開くと、元のウィンドウは **操作専用モード**（上に小さなプレビュー、下に操作パネル）になります。
「細い別窓に」を押すと、操作パネルだけが幅 340px の細い別窓になって画面右端に出ます（もう一度押すか、別窓を閉じると元に戻ります）。
別窓で「PCの音」を取り込んだ場合、別窓を閉じると音の取り込みも止まります。
