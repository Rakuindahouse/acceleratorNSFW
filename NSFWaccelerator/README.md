# ebb flow mixer

[ebb and flow](https://htg0707kym-lgtm.github.io/ebb-and-flow-artwork/) をベースにした映像ミキサー。
画面を斜めに分割したパネルに素材を流し、流速・うねり・残像を操作しながら全体の色を変えられます。

## 起動

`index.html` をダブルクリックするだけで動きます（Chrome / Edge 推奨）。インストールは不要です。
既定のブラウザが Chrome / Edge 以外の場合は、`index.html` を Chrome の画面にドラッグしてください。

## できること

| 機能 | 操作 |
| --- | --- |
| 好きな画像・動画 | 「画像・動画を追加」/ ドラッグ＆ドロップ / Ctrl+V 貼り付け |
| Spout ソース | 「Spout / カメラ」→ SpoutCam を選んで「追加」 |
| サイトの画像 | 絵の具(19) / 海：青(65) / 海：白(52) をチェックで ON/OFF |
| 素材の混ぜ具合 | 「自分の素材」スライダー（1 で自分の素材だけ） |
| 動き | 分割数・傾き・切替秒・フェード・流速・うねり・残像・ズーム |
| 全体の色 | プリセット、色相・彩度・明るさ・コントラスト・ガンマ、色置換（影/中間/光の3色）、色かぶり、反転、周辺減光 |
| 音の入力 | 「マイク / ライン」「PCの音」「音声ファイル」 |
| 保存 | 「画像保存」で PNG。設定は自動で記憶 |

キー: `H` パネル表示切替 / `F` 全画面 / `N` 次の配置 / `Space` 押している間だけ高速に明滅。
スライダーはダブルクリックで初期値に戻ります。

## 音に反応させる

元作品と同じく、音で映像が動くようになっています。入力は3種類です。

- **マイク / ライン**: オーディオIF・マイク・VB-CABLE・ステレオミキサーなど。デバイスを選んで「使う」
- **PCの音**: 画面共有ダイアログで画面を選び、「システム音声を共有」をオン（Windows の Chrome / Edge）
- **音声ファイル**: 選んだ曲を再生しながら反応させます（スピーカーからも鳴ります）

音は 低音・中音・高音 に分けて解析し、次のように反映します（スライダー 0 でオフ）。

| スライダー | 反応 |
| --- | --- |
| 入力感度 | 全体の反応の強さ |
| ビート切替 | 低音のアタックで配置を切り替え（右ほど敏感） |
| 最短間隔(秒) | ビート切替が連続しすぎないための間隔 |
| 低音→うねり | 低音でうねりが強くなる |
| 音量→流速 | 大きい音ほど速く流れる |
| 高音→明るさ | 高音で明るくなる |
| ビート→光 | ビートの瞬間に光る |
| 静けさ→残像 | 静かな部分ほど残像が長く残る |

## Spout の受け方

ブラウザは Spout を直接受け取れないため、Spout 公式の **SpoutCam** を使います。

1. [Spout](https://spout.zeal.co/) をインストールし、付属の `SpoutCamSettings` で SpoutCam を登録
2. 送りたいアプリ（TouchDesigner / Resolume / OBS + Spout プラグインなど）で Spout 送信
3. このアプリで「Spout / カメラ」→ `SpoutCam` を選択 → 追加

複数の Spout ソースを使う場合は SpoutCam を複数登録してください（SpoutCam1〜4）。
OBS の「仮想カメラ」も同じ手順で使えます。

## Spout / NDI で出力する

ブラウザは直接 Spout / NDI を送れないので、OBS を経由します。

1. `start.bat` で起動（裏に隠れても描画が止まらない専用ウィンドウで開きます）
2. 「出力」で解像度（例: 1920 × 1080）を選び、「出力ウィンドウ」を押す → 映像だけのウィンドウが開く
3. OBS で「ウィンドウキャプチャ」→ `ebb flow output` を選択（キャプチャ方式は「Windows 10 (1903以降)」）
4. 送り出し
   - **Spout**: OBS に [Spout2 プラグイン](https://github.com/Off-World-Live/obs-spout2-plugin) を入れ、ツール → Spout Output Settings → Start
   - **NDI**: OBS に [DistroAV (旧 obs-ndi)](https://github.com/DistroAV/DistroAV) と NDI Runtime を入れ、ツール → DistroAV NDI Settings → Main Output をオン

出力ウィンドウを開くと、元のウィンドウは **操作専用モード**（上に小さなプレビュー、下に操作パネルの縦長レイアウト）になります。
Resolume などの横に置く場合は、ウィンドウの幅を縮めて画面の端に寄せてください。（「右端に縦長」ボタンはブラウザが許す場合だけ効きます）
「プレビュー」ボタンでプレビューを隠すと、操作パネルだけになります。出力ウィンドウを閉じると元の表示に戻ります。
OBS のキャンバス解像度を出力解像度と合わせると綺麗に出ます。
